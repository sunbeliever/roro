# roro

一个轻松使用的小网页。网站首页为 index.html，旧文件名也会跳转到首页。

私人内容仅以 AES-256-GCM 密文保存；打开信息不在仓库中。只有完整专属链接才能在浏览器解锁，请私下发送。

网页提供选剧、风景与天气、随机照片配对、运动安排。公开剧集和天气由 GitHub Actions 每半小时尝试采集一次，可能排队或失败；页面保留实际采集时间并拒绝过期结果。剧名搜索仍访问 TVmaze 公开接口，受访问者网络条件影响。

数据来源：豆瓣公开片单、TVmaze（CC BY-SA）、Open-Meteo。GitHub Pages 免费公共托管；国内网络和微信安全提示仍以实际手机测试为准。
